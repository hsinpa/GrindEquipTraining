# Unity C# compile check

After creating or editing Unity C# scripts, run the helper from the project root:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".pi/skills/unity-csharp-compile-check/scripts/Test-UnityCSharp.ps1"
```

The helper:

1. Finds the newest `Assembly-CSharp.rsp` generated by Unity Bee.
2. Locates the matching Unity Editor installation from the open editor process or `ProjectVersion.txt`.
3. Copies and rewrites the response file so compiler output goes to `Temp/UnityCompileCheck` rather than Unity's Bee artifacts.
4. Invokes Unity's bundled Roslyn `csc.dll` with the same references, defines, analyzers, and language version used by Unity.
5. Returns a nonzero exit code on compilation errors.

Use `-Assembly <name>` for another generated assembly:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".pi/skills/unity-csharp-compile-check/scripts/Test-UnityCSharp.ps1" -Assembly "Assembly-CSharp-Editor"
```

Use `-Source <relative-path>` when a newly created script has not yet been added to Bee's response file:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".pi/skills/unity-csharp-compile-check/scripts/Test-UnityCSharp.ps1" -Source "Assets/Example/NewScript.cs"
```

Report compile errors separately from existing warnings. This verifies C# only; shader compilation still requires Unity's Shader Importer.
